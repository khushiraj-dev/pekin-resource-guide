# Pekin Area Community Resource Guide

A searchable, categorized directory of community resources for Tazewell County, Illinois, built for [United Way of Pekin](https://www.unitedwayofpekin.org/) as part of a data consulting engagement with StatCom at UIUC.

🔗 **Live site: [pekin309.guide](https://pekin309.guide/)**

---

## Overview

The Pekin Area Community Resource Guide digitizes and replaces United Way of Pekin's printed resource book, making 140+ local services searchable and accessible online. Residents can browse resources by category or search by name and tag to find help with food, housing, mental health, youth services, and more.

United Way of Pekin serves thousands of Tazewell County residents annually, including:
- 1,500+ clients through affiliated food pantries
- 7,000+ students through youth and childcare programs
- 2,100+ showers and 50,000+ student snack packs delivered through outreach programs

---

## Features

- 140+ community resources sourced from CSV data
- Category-based browsing and tag/name search
- Sidebar table of contents for quick navigation
- Google Maps thumbnails for each resource location
- Mobile-responsive layout
- Custom domain deployment

---

## Tech Stack

- HTML, CSS, JavaScript
- Google Maps Embed API
- Deployed via GitHub Pages with custom domain
